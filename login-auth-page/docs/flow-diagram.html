🔄 Token Lifecycle

🔑 Access Token

Type: JWT HS256
Expiry: 7 hari
Storage: Client localStorage
Server: Stateless (tidak disimpan)
Digunakan: Authorization header

🔄 Refresh Token

Type: JWT HS256
Expiry: 30 hari
Storage: Client localStorage + Server DB
Digunakan: POST /auth/refresh
Rotation: Dihapus & diganti setiap refresh
