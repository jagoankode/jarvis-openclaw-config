### ✅ Continue.dev
- **Open source**, VS Code extension
- Bisa colok ke **any OpenAI-compatible API** — DeepSeek, OpenCode, Claude, Gemini, lo name it
- Support **inline tab autocomplete** + **chat**
- Cara setup:
  1. Install extension "Continue" dari VS Code marketplace
  2. Config di `~/.continue/config.json`:
  ```json
  {
    "models": [
      {
        "title": "DeepSeek",
        "provider": "openai",
        "model": "deepseek-v4-pro",
        "apiKey": "***",
        "apiBase": "https://api.deepseek.com/v1"
      }
    ],
    "tabAutocompleteModel": {
      "title": "DeepSeek",
      "provider": "openai",
      "model": "deepseek-v4-flash",
      "apiKey": "***",
      "apiBase": "https://api.deepseek.com/v1"
    }
  }
  ```

Buat OpenCode tinggal ganti `apiBase`-nya ke endpoint OpenCode.
