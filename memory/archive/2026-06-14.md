## 🚨 PR Review — Critical Rules
1. **WAJIB `git switch [SOURCE]` dulu** sebelum jalanin ESLint/test — jangan review dari branch lain!
2. **WAJIB `git pull origin [SOURCE]`** — pastikan file yang di-scan = file di remote branch yang di-review
3. **HANYA file yang diubah (diff files)** — gak boleh scan full project
4. **Jangan pake file lokal dari branch lain** — ESLint harus dari branch yang bener
5. Pastikan tahu branch mana SOURCE dan mana TARGET, jangan terbalik
6. Kalau ragu isi file, cek dengan `git show origin/[BRANCH]:[FILE]`

## 🧹 PR Review — Branch Cleanup Wajib
Setelah selesai review, WAJIB:
1. `git switch development` (atau branch stabil)
2. `git branch -D [SOURCE-BRANCH]` — hapus local tracking branch
3. Jangan tinggal di branch source — numpuk local branch

## 🚨 Worktree Creation — Step by Step
WAJIB tanya dulu: branch name, folder name, base branch.

Steps:
1. Tentukan main repo — cek existing worktree:
   `cat /var/www/html/project-asum/[existing-worktree]/.git`
   → dapat `gitdir: /path/to/main-repo/.git/worktrees/...`
   → main repo = `/path/to/main-repo` (tanpa .git/worktrees)

2. `cd [MAIN-REPO]`
3. `git fetch origin [BASE-BRANCH]`
4. `git worktree add -b [BRANCH-NAME] [FOLDER-PATH] origin/[BASE-BRANCH]`

5. Apply code changes di worktree folder

Jangan: bikin dari repo utama `~/project/epics-portal` — itu buat review PR!
