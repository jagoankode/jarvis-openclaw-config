## Latest Changes
### Cascade Delete (updated)
- `org delete` → deletes workflow_runs → tasks → employees → teams → divisions (cascade full)
- `div delete` → deletes employees, teams under that division
- `team delete` → sets employees' `team_id` to NULL (tidak cascade hapus employee)

### Standalone Persona + Many-to-Many
- **Command:** `persona list/create/edit/delete` (standalone, bukan subcommand emp)
- **Many-to-many:** `personaIds` array — 1 employee bisa punya banyak persona, 1 persona bisa dipake banyak employee
- **Schema:** `personaId` (single) diubah jadi `personaIds` (TEXT JSON array)
- **Backward compat:** `emp create -p senior-dev` masuk ke `personaIds[0]`
- **Display:** `emp info` dan `emp list` nampilin persona names dari array

### Employee Standalone + Assign/Unassign
- **`emp create`** — no longer requires `-o`/`--div`/`--team` (standalone by default)
- **`emp assign <id> -o <org>`** — dedicated assign command
- **`emp unassign <id>`** — dedicated unassign command
- **`emp info`** — shows Org/Div/Team or "-" if unassigned
- **Cascade delete updated:** `org delete` unassigns employees (doesn't delete them), `div delete` unassigns employees
- **DB migration:** `org_id`, `div_id`, `team_id` columns now nullable in SQLite
