### Lesson: Review convention checklist lengkap

Pas review PR, jangan cek ESLint source files doang. Wajib:
1. ESLint source files (changed files only)
2. ESLint test files (changed files only)
3. TypeScript typecheck (changed files only — `tsc --noEmit` terus grep)
4. Jest tests di scope module

Biar gak kelamaan nunggu full compile, cukup **scope ke changed files** aja.
