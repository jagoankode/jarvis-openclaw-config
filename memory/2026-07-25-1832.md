```
sudo cloudflared service install /etc/cloudflared/config.yml
```

1. File config/token disimpan ke lokasi standar
2. systemd service `cloudflared` dibuat + enabled
3. Service langsung start — tunnel jalan terus walaupun VPS restart
4. Cek status: `sudo systemctl status cloudflared`

### 2. Managed Tunnel — yang bener ✅
Bikin tunnel baru cukup:
```
cloudflared tunnel create tunnel-baru
cloudflared tunnel route dns tunnel-baru subdomain.domain.com
```
Terus edit `/etc/cloudflared/config.yml` — tambahin ingress entry baru:
```yaml
tunnel: tunnel-utama
credentials-file: /etc/cloudflared/xxx.json

ingress:
  - hostname: service1.domain.com
    service: http://localhost:3001
  - hostname: service2.domain.com
    service: http://localhost:3002
  - service: http_status:404
```

**Gak perlu `service install` lagi** — cukup restart service-nya:
```
sudo systemctl restart cloudflared
```

| Managed tunnel, awal setup pertama | ✅ Satu kali aja |
