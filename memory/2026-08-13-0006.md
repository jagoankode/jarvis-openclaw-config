Fortify biasanya deteksi kategori ini:

## OWASP Top 10 (wajib)

| Kategori | Contoh di Next.js |
|----------|-------------------|
| **Injection** | SQL injection, NoSQL injection, Command injection lewat API routes |
| **Broken Auth** | Session handling lemah, JWT tanpa expiry, missing CSRF |
| **Sensitive Data Exposure** | `.env` atau `NEXT_PUBLIC_*` bocor, hardcoded API key, secrets di client bundle |
| **XSS** | `dangerouslySetInnerHTML`, `innerHTML`, render user input mentah |
| **Broken Access Control** | Route protection kurang, Server Action missing auth check |
| **Security Misconfig** | CSP headers kurang, CORS too permissive, debug mode production |
| **SSRF** | `fetch()` dari user-supplied URL tanpa validasi di API routes / `getServerSideProps` |

## JavaScript/TS Spesifik

- **Prototype pollution** — `Object.assign`, spread operator di deep merge
- **Open redirect** — `router.push(userInput)` tanpa validasi
- **Insecure deserialization** — `JSON.parse()` tanpa schema validation
- **Path traversal** — `fs.readFile(userPath)` di API routes
- **ReDoS** — regex vulnerable di server-side
- **Supply chain** — dependency dengan known CVE
- **Secrets in code** — API keys, token, password hardcoded
- **Log forging** — input user masuk log tanpa sanitasi

- JavaScript/TypeScript SCA → kode

- Content Security → headers
- OWASP Mobile/Web → API routes
- Cryptography → hash/encryption issues
```

## Intinya
