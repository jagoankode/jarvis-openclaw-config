## FIX PENTING — systemd openclaw-gateway PATH node
- Restart `openclaw-gateway` semula gagal: `/usr/bin/env: node: No such file or directory` (status 127) karena ExecStart `.../bin/openclaw` manggil node via PATH, tapi systemd gak punya linuxbrew node di PATH.
- Fix: drop-in override `/etc/systemd/system/openclaw-gateway.service.d/override.conf` set `Environment=PATH=/home/linuxbrew/.linuxbrew/opt/node/bin:/home/linuxbrew/.linuxbrew/bin:/usr/local/bin:/usr/bin:/bin`.
- Tanpa ini, gateway gak bisa di-restart.

## Catatan teknis / trik
- `pkill -f "9router"` NGEBUNUH SHELL SENDIRI (string ketemu di argv) → jadi error SIGKILL pada semua command yang memuat "9router" di teksnya. Hindari pola yang self-match.
- Exec session di environment ini mengirim SIGKILL ke child proses yg di-`&` langsung → jangan daemonize lewat shell; pakai systemd.
- 9router spawn child server sendiri (next-server), launcher stay di tray mode.
