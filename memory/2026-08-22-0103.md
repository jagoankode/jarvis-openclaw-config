user: Tailscale untuk apa?
assistant: Tailscale = VPN mesh pribadi berbasis WireGuard. Gunanya: nyatukan device lo (laptop, VPS, HP) dalam satu jaringan privat — saling akses meski masing-masing di belakang NAT/router.

**Kenapa relevan ke kasus tadi:**
- Laptop lo biasanya di belakang router rumah/kantor — **gak punya public IP**, jadi VPS gak bisa SSH masuk dari luar.
- Solusi manual: port forwarding di router + expose SSH ke internet — ribet & rawan diserang.
- Tailscale: laptop dapet IP privat (misal `100.64.x.x`), VPS join network yang sama → **VPS tinggal `ssh user@100.64.x.x`**, jalan langsung. Tanpa setting router, tanpa buka port.

**Cara pakai:**
1. Install Tailscale di laptop + VPS (`curl -fsSL https://tailscale.com/install.sh | sh`)
2. `tailscale up` di dua-duanya, login akun yang sama
3. Selesai — dua device saling ping/SSH

Free tier cukup buat personal (100 device). Alternatif: ZeroTier (mirip), atau kalau laptop udah punya public IP / udah di network yang sama, gak perlu Tailscale sama sekali.
