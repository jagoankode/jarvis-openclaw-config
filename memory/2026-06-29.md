#### PDF Preview Fix (Key Learning)
**Issue:** Hierarchical numbering & formulas not rendering in PDF preview.

**Root cause (double):**
1. CSS selectors scoped to `.document-composer-quill-wrapper .ql-editor` — but PDF HTML is bare `editor.root.innerHTML` without wrapper classes
2. CSS counters not supported reliably in PDF API rendering

**Fix approach — Pre-compute numbers in JS:**
- Added `_computePdfListNumbers()` function in `DocumentComposer.component.tsx` that parses HTML, computes hierarchical numbers per indent level, and embeds as `data-number` attribute on `.ql-ui` spans
- Added un-scoped CSS to `DOCUMENT_COMPOSER_PRINT_CSS` using `content: attr(data-number) ". "`
- KaTeX CSS added to `DOCUMENT_COMPOSER_GLOBAL_CSS` via generated `katex.css.ts` file (imported + interpolated as template string)
