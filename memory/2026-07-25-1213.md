FREQUENTLY ASKED QUESTIONS (FAQ) :
1. Apa itu RUSPIN?
RUSPIN (Rumah Unggul Sistem Panel Instan) adalah teknologi struktur bangunan pracetak (precast) yang dikembangkan dari hasil riset Kementerian
PUPR Republik Indonesia.
RUSPIN berfungsi sebagai pengganti struktur konvensional seperti sloof, kolom, dan ring balok yang biasanya dicor di lokasi proyek. Seluruh panel
diproduksi terlebih dahulu di workshop dengan standar kualitas yang terkontrol, kemudian dikirim ke lokasi untuk dirakit menggunakan sistem
sambungan baut. Keunggulan utama RUSPIN adalah proses pembangunan yang lebih cepat, lebih presisi, lebih efisien, dan lebih tahan gempa
dibanding metode konvensional.

HARGA & PERHITUNGAN BIAYA
2. Berapa harga panel RUSPIN?
Harga panel RUSPIN dihitung per unit panel.

3. Apa saja yang termasuk dalam biaya pembangunan menggunakan RUSPIN?
Komponen biaya pembangunan struktur RUSPIN terdiri dari:
• Material panel RUSPIN
• Mur, baut, plat sambungan dan aksesoris lainnya
• Biaya pemasangan struktur
• Biaya transportasi material
• Biaya transportasi tenaga kerja
• Pondasi (opsional)
Pondasi dapat dikerjakan sendiri oleh pemilik atau dikerjakan oleh tim kami.
4. Bagaimana cara menghitung kebutuhan panel dan biaya proyek?
Perhitungan dilakukan berdasarkan desain bangunan.

1. Menentukan kebutuhan ruang dan desain bangunan.
2. Membuat gambar desain.
3. Menghitung kebutuhan panel RUSPIN.
4. Menghitung kebutuhan material pendukung lainnya.
5. Menyusun Rencana Anggaran Biaya (RAB).
Karena itu, total biaya tidak dapat dihitung hanya berdasarkan luas bangunan tanpa melihat desainnya terlebih dahulu.

Pada banyak kasus, ya.

atau menghasilkan pendapatan.

## 🚇 Cara Tunnel localhost:3000 → jagoankode.site

### 1. Install cloudflared

```bash
# Linux (amd64)
wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
chmod +x cloudflared-linux-amd64
sudo mv cloudflared-linux-amd64 /usr/local/bin/cloudflared
```

Atau pake package manager:
```bash
# Ubuntu/Debian
sudo dpkg -i cloudflared-stable-linux-amd64.deb
```

### 2. Login ke Cloudflare

```bash
cloudflared tunnel login
```
Bakal kebuka browser → login Cloudflare → pilih domain **jagoankode.site** → authorized.

### 3. Buat Tunnel

```bash
cloudflared tunnel create jagoankode-tunnel
```
Bakal generate **credentials file** (JSON) di `~/.cloudflared/`.

### 4. Konfigurasi Tunnel

Bikin file `~/.cloudflared/config.yml`:

```yaml
tunnel: <tunnel-id-dari-step-3>
credentials-file: /home/user/.cloudflared/<tunnel-id>.json

ingress:
  - hostname: jagoankode.site
    service: http://localhost:3000
  - service: http_status:404
```

### 5. Route DNS

```bash
cloudflared tunnel route dns jagoankode-tunnel jagoankode.site
```

Ini otomatis bikin **CNAME** jagoankode.site → tunnel-id.cfargotunnel.com di DNS Cloudflare.

### 6. Jalankan Tunnel

```bash
# Manual — test dulu
cloudflared tunnel run jagoankode-tunnel

# Atau install sebagai service (biar auto-start)
sudo cloudflared service install
```

Done! ✅ Domain **jagoankode.site** langsung nunjuk ke **localhost:3000** lo.

---

### ⚡ Tips

| Kebutuhan | Command |
|-----------|---------|
| **Subdomain** | `cloudflared tunnel route dns jagoankode-tunnel app.jagoankode.site` |
| **Multiple service** | Tambah entry di `ingress[]` config.yml |
| **Stop tunnel** | `sudo systemctl stop cloudflared` |
| **Log** | `sudo journalctl -u cloudflared -f` |
| **Ngubah config** | Edit `config.yml` → `sudo systemctl restart cloudflared` |

**Kelebihan pake Cloudflare Tunnel:**
- ✅ Gak perlu buka port di router/firewall
- ✅ Auto HTTPS/SSL (Cloudflare handle)
- ✅ DDoS protection gratis
- ✅ Bisa akses dari mana aja tanpa IP publik
