- **Tes:** unit test hooks + integration (MSW mock API)

- Storage (AsyncStorage / MMKV / SQLite)
- Analytics / Crashlytics
- Notification handler

Semua komunikasi keluar aplikasi → lewat sini, **screens never call fetch langsung**.

### 4️⃣ **Platform Layer (Native)**
- Native modules (camera, biometric, push notif)
- Turbo Modules / Fabric (New Architecture RN)
- Bridge ke Java/Kotlin/Swift/ObjC

### 🎯 **Structure Folder Rekomendasi**

```
src/
├── app/            # Root: navigator, providers
├── screens/        # Screen components
├── components/     # Shared UI components
├── hooks/          # Custom hooks (logic)
├── store/          # Zustand slices / Redux
├── services/       # API client, storage, etc.
├── utils/          # Pure functions, helpers
├── types/          # TS types/interfaces
├── constants/      # Env, config, enums
└── __tests__/
```

### ⚡ **Key Principles**
- **Separation of concern** — screen jangan tahu soal storage/cache
- **Dependency injection** lewat context/props — gampang mock pas test
- **Platform code** diisolasi di folder `native/` atau `platform.xxx.ts` (file extension-based)
- **Tes di tiap layer** — unit (utils), integration (hooks/services), E2E (Detox)

---

**Pendapat pribadi:** Buat startup/medium app, **Zustand + TanStack Query + minimal services layer** udah cukup. Jangan over-architect dari awal — scalable secukupnya aja, refactor kalau udah terasa berat.
