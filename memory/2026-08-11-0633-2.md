### Root cause: Next.js 16 gak terima relative path di redirect!

`NextResponse.redirect('/admin')` → **ERROR**: *"URL is malformed '/'. Please use only absolute URLs"*

**Fix:** Bangun absolute URL dari `Host` header + `x-forwarded-proto`, bukan dari `request.url` (yang balikin `localhost:3002` pas lewat Cloudflare tunnel).

```ts
// ❌ Sebelumnya: request.url → localhost:3002 → redirect ke domain salah
new URL(redirect, request.url)  // https://localhost:3002/admin

// ✅ Sekarang: Host header → domain publik
const host = request.headers.get('host')  // sso.jagoankode.site
const proto = request.headers.get('x-forwarded-proto') // https
new URL(redirect, `${proto}://${host}`)  // https://sso.jagoankode.site/admin
